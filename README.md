# Hifdh Helper

A free Quran memorisation (hifz) tracker and planner: daily targets for new hifz (sabaq), new revision (sabqi) and older revision (manzil), with spaced repetition and hard-page reviews.

Live at https://hifdh-helper.ummahapps.ai/

A static site with no build step. Plans and logs are saved in the browser on each device.
