# Hifdh Helper

A free Quran memorisation (hifz) tracker and planner: daily targets for new hifz, spaced repetition new revision and a full older revision cycle, with surah-by-surah revision progress, hard-page reviews, and modes for being sick, travelling or on a period.

Live at https://hifdh-helper.ummahapps.ai/

A static site with no build step. Plans and logs are saved in the browser on each device.
