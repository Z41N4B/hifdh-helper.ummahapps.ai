# Hifdh Helper

A free Quran memorisation (hifdh) tracker and planner: daily targets for new hifdh, spaced repetition new revision and a full older revision cycle, with surah-by-surah revision progress, hard-page reviews, modes for being sick, travelling or on a period, a Ramadan mode with a khatm reading tracker, and a chart of past revision cycles.

Live at https://hifdh-helper.ummahapps.ai/

A static site with no build step. Plans and logs are saved in the browser on each device.
